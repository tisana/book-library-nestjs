## Compiler and loader

Root/build/performance compilation uses TypeScript 6 NodeNext module and resolution settings. With no `type: module`, emitted application JavaScript remains CommonJS. Root `rootDir: .` supports scripts, migrations and tests; the production config explicitly includes `src/**/*.ts`, excludes tests/specs, and sets `rootDir: src`. A clean build emits `dist/main.js`, and the production harness launches that exact file. Performance retains its original repository root and `dist-performance/scripts/verify-auth-performance.js`. [Artifact evidence](evidence/t3/compiler-artifacts.json) confirms both entries and enabled decorator metadata.

`strict: false` explicitly preserves the preceding compiler default; TypeScript 6 otherwise enables stricter checks implicitly. Root Node/Jest types preserve existing test globals. The import audit found no root aliases requiring `baseUrl`; it was removed. Two existing Nest deep imports use the exported `@nestjs/common/constants` entry. Callable Supertest namespace imports were changed consistently to default imports. Decorated interfaces use type-only imports, and the crypto spy targets the mutable Node default export. No route, security service or schema behavior changed.

Jest 30.2.0 could not load Nest 12 ESM. The coordinator approved the smallest demonstrated official loader fix: exact **Jest 30.4.1**, with `node --experimental-vm-modules` on existing Jest npm entries. 30.4.0 introduced native synchronous ESM support but actual loading exposed the tslib default-interop issue fixed in 30.4.1. [Decision evidence](evidence/t3/jest-loader-decision.md) records official sources, peer/engine/advisory checks, rejected alternatives and real failure outcomes. The application remains CommonJS.

Ordinary ts-jest uses a separate fully typechecked TypeScript 6 CommonJS/Bundler config with `isolatedModules: false` and `esModuleInterop: true`. This preserves resolved decorator metadata and the baseline coverage branch graph. An isolated transpile trial added generated metadata fallback branches; it was removed. No custom transformers, dependency patches, deprecation suppression, coverage exclusions, fabricated fallback tests or floor changes remain. Root and test no-emit compilation both pass.
